# Enove · Manual de Identidade Visual

Site estático com o Manual de Identidade Visual da Enove Imobiliária.

## Estrutura
- `index.html` — página única do manual
- `site.css`, `site-sections.css`, `site-apps.css`, `site-mockups-2.css`, `site-real-mockups.css` — estilos
- `assets/` — logos, mockups, PDFs e imagens
- `fonts/` (se aplicável) — fontes locais
